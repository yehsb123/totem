# 결정 대기 목록

자율 작업 중 코드로 정할 수 없어 보류한 항목. 결정을 주시면 "결정 후 할 일"을 진행합니다.
각 항목의 발견 경위는 `docs/WORKLOG.md`, 근거는 괄호 안 문서 절.

- 급함 = 운영 전에 반드시 필요하거나 보안 위험이 계속되는 것
- 권장안은 지금 코드·운영 조건 기준의 제안이며, 다른 선택을 하셔도 코드는 대응 가능
